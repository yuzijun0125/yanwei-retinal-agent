# 眼维知识图谱第一版

## 直接看结果

双击`眼维知识图谱.html`，不需要联网、安装Neo4j或配置模型。可以搜索术语/编号、点击节点、查看关系来源与待复核字段，并查询黄斑区出血参考区域。

这是一份**规则程序构建的可追溯基线**，不是论文多智能体模型的完整复现。没有调用大模型、没有训练MLP、没有修改或接入当前Nexent发布版。

## 文件

- `眼维知识图谱.html`：可独立打开的交互图谱。
- `artifacts/graph.json`、`graph.sqlite`：实际节点、关系与来源。
- `artifacts/nodes.csv`、`relations.csv`：可在表格工具查看的实体与关系。
- `artifacts/review_queue.json`：631条项目推导字段复核清单；其他导入或人工整理记录也不代表医学审核通过。
- `artifacts/query_examples.json`：已运行查询的完整路径结果。
- `artifacts/build_report.json`：构建统计。
- `inputs/`：本次使用的派生表快照，不含原始影像、患者病历、模型权重或服务密钥。
- `后续多智能体配置草案.json`：尚未平台注册或执行的角色草案，不是实际多智能体调用记录。
- `老师要求怎么理解与下一步.md`：用简单话解释论文、老师可能的意图和剩余工作。

## 重建与测试

Python 3.11或以上，图谱构建与查询仅用标准库。在本目录执行：

```bash
python build_graph.py --source inputs
python -m unittest test_graph
python query_graph.py "黄斑区出血参考病例"
python query_graph.py "CASE_IDRiD_000055"
```

HTML已内嵌数据，可以直接打开；如果浏览器限制本地文件，可执行`python -m http.server 18887 --bind 127.0.0.1`，访问该目录的HTML文件。默认只本机访问。

## 必须知道的限制

81条病例是项目按图片聚合的记录，不等于81个患者；363条挂接文本来自项目派生记录，含合成材料，不是真实临床病历。位置、程度和眼别存在自动推导，保留待复核状态。MENTIONS只表示提及，不能当作病灶肯定存在。

6条基础医学关系是人工根据公开来源整理的示例，未做本地专家审核；所引NEI手册为历史科普来源，本原型只使用基础概念，不采入治疗或随访建议，不声称已对齐最新诊疗规范。IDRiD论文示例支持病灶相关性，不能单凭病灶诊断患者。

没有报告抽取F1、临床准确率或论文效果复现成功。测试通过只表示本轮图数据与查询约束被检查。

原图及既有派生记录的归属按IDRiD及项目原说明保留，模型和论文不是团队自行训练或创作。没有重新分发老师提供的论文全文。
