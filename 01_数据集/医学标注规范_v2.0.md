# 眼维数据集 · 医学标注规范 v2.0

> 版本：v2.0（取代 v0.5.0/v0.4.0 医学标注手册）｜ 编制：管道通（数据工程）｜ 日期：2026-10-13
> 定位：**可执行作业指导书**。标注员、复核医生、脚本三方共用同一份规则。
> 最高原则：**未知 ≠ 阴性**。任何不确定项必须留 `UNKNOWN` 并记录来源，绝不默认填充。

## 0. v2.0 相对 v0.6 的四处根本改动

| # | 改动 | 原因 |
|---|---|---|

## 1. 标注对象与粒度

一条标注 = **一个病灶类型 × 一处的描述**。同一图像多个病灶 → 多条标注。

| 粒度 | 产出表 | 触发条件 |
|---|---|---|
| 图像级疾病严重度 | `silver_grading` | 有官方分级或专家判读 |
| 病灶级 | `silver_lesion` | 有病灶描述或专家掩膜 |
| 区域级 | `silver_region` | 有掩膜或候选框 |

## 2. 眼别判定规程（⚠️ 本版最重要的"待验证项"）

### 2.1 问题现状

- IDRiD **官方不提供眼别字段**（已核实：官方只提供病灶/视盘像素级掩膜、DR/DME 分级、视盘与黄斑中心坐标）。
- 现有 81 例眼别全部由"视盘中心相对横坐标"推导，标注为"待复核"，但**没有任何真值可以复核它**。
- 眼科文献中存在**两种相反的约定**，且视盘位置与眼别的关系在不同设备/镜像设置下可能翻转。**仅凭记忆或惯例确定方向，风险极高。**

### 2.2 三种来源的优先级

| 优先级 | `eye_source` | 说明 |
|---|---|---|
| 1（最高） | `OFFICIAL` | 数据集/设备/报告直接给出眼别（如 ODIR、OIA-ODIR 的左右眼列，EyePACS 文件名的 left/right） |
| 2 | `REVIEWED` | 医学人员看图像本身判读确认（注意：需确认其判读依据） |
| 3（最低） | `DERIVED_OD_FOVEA` | 按视盘相对位置自动推导 |
| — | `UNKNOWN` | 无从判断 |

### 2.3 视盘推导规则必须"先验证、再启用"

**不允许**直接把某一种推导方向写死进代码。执行下列三步：

```
步骤1  取一个有眼别真值的公开集（EOIR / OIA-ODIR / EyePACS 任一，≥50 张）
步骤2  对每张图计算：视盘中心 x 是否 > 图像中心 x，得到二值预测
步骤3  与真值比对，计算准确率
        准确率 ≥ 90%  → 该方向成立，启用为默认规则
         准确率 ≤ 10%  → 方向相反，翻转后启用
        10% < 准确率 < 90% → 规则不可靠，一律标 UNKNOWN，不得推导
```

**工程要求**：推导方向写成**配置项**（`eye_rule_direction: DISC_RIGHT_means_OD | DISC_RIGHT_means_OS`），翻转只需改配置，不改代码。

> **当前风险提示**：现有 81 例中，"视盘在图像右侧"被推导为**左眼（OS）**，共右眼 43 / 左眼 38。按标准视网膜解剖关系（视盘位于**鼻侧**、黄斑位于**颞侧**）推演，该方向存在反向的可能。**在完成上述三步验证之前，这批眼别字段一律视为不可用，且不得计入"眼别冲突率"指标**（对应质量规则 `EY-01`）。

### 2.4 冲突裁决

| 冲突情形 | 处理 |
|---|---|
| 文件名与报告冲突 | 以报告为准，`review_status=ARBITRATION`，记录冲突双方 |
| 报告与图像冲突 | 以图像人工判读为准，`eye_source=REVIEWED` |
| 无法判定 | `eye=UNKNOWN`，**不得猜测** |

## 3. 图像级分级标注（ICDR 标准，权威依据）

**依据**：Wilkinson CP, et al. *Proposed international clinical diabetic retinopathy and diabetic macular edema disease severity scales.* Ophthalmology. 2003;110(9):1677-1682.

### 3.1 DR 分级（`dr_grade` 0—4）

| 值 | 名称 | 判据 |
|---|---|---|
| 0 | 无明显视网膜病变 | 无异常可见 |
| 1 | 轻度 NPDR | **仅有**微血管瘤（MA） |
| 2 | 中度 NPDR | 介于轻度与重度之间（多于 MA，但未达重度） |
| 3 | 重度 NPDR | 以下任一：>20 个视网膜内出血（4 象限均可见）/ 静脉串珠样改变（≥2 象限）/ 视网膜内微血管异常 IRMA（≥1 象限）/ **无 PDR 征象** |
| 4 | PDR | 以下任一或两者：新生血管 / 玻璃体或视网膜前出血 |

### 3.2 DME 分级（`dme_grade` 0—2）

| 值 | 判据 |
|---|---|
| 0 | 无明显硬性渗出 |
| 1 | 硬性渗出位于**黄斑中心 1DD（视盘直径）之外** |
| 2 | 硬性渗出位于**黄斑中心 1DD 之内** |

> **1DD 定义**：以视盘直径为标尺的距离单位。标注时必须记录所用标尺（`1DD ≈ 视盘直径`），避免不同标注员口径不一。

### 3.3 标注纪律

- 分级**只能**来自官方标注或专家判读，`grading_source` 必须写 `OFFICIAL`；自动分类结果**不得**写入分数字段（可另存为 `predicted_grade`，不参与评测）。
- `dr_grade=0` 表示"判读为无病变"，与"未判读"（留空）**语义不同**，禁止混用。

## 4. 病灶标注规则（`silver_lesion`）

### 4.1 病灶类型（枚举 + 判据）

| 枚举 | 中文 | 判据要点 | 易混淆项 |
|---|---|---|---|
| `MA` | 微血管瘤 | 边界较清楚的**小红色圆点**；需与出血点区分（直径更小、边界更清） | HE |
| `HE` | 出血 | 点状/片状/火焰状出血，按原文记录深线与范围 | MA、IRMA |
| `EX` | 硬性渗出 | 边界清晰的**黄白色**蜡样沉积 | 玻璃膜疣（drusen） |
| `SE` | 棉絮斑（软性渗出） | 边界模糊的**灰白色**棉絮状斑 | 硬性渗出 |
| `DRUSEN` | 玻璃膜疣 | 位于 RPE 层的黄色小沉积，**不得与 EX 混用** | EX |
| `IRF` | 视网膜内液 | **必须**有 OCT 等模态支持 | — |
| `SRF` | 视网膜下液 | **必须**有 OCT 等模态支持 | — |
| `OTHER` | 其他 | 不在词表内，**须在 `evidence_span` 保留原名** | — |
| `UNKNOWN` | 未知 | 无法归类 | — |

> **规则**：`IRF` / `SRF` 在仅有 CFP 模态时**不得标注**（不可见），必须 `UNKNOWN`。这是"模态一致性"门禁的医学基础。

### 4.2 位置（`location`）

| 枚举 | 定义 |
|---|---|
| `MACULA` | 黄斑区（后极部核心区域） |
| `FOVEA` | 黄斑中心凹，**需明确原文或医学复核**，不得由"黄斑区"自动升级 |
| `POSTERIOR_POLE` | 后极部（范围大于黄斑区） |
| `TEMPORAL` / `NASAL` | 颞侧 / 鼻侧，**与眼别相关**——眼别为 `UNKNOWN` 时，颞/鼻侧描述不可用于跨病例比较 |
| `DISC` | 视盘区 |
| `OTHER` / `UNKNOWN` | 其他 / 未知（**禁止默认填 MACULA**） |

### 4.3 程度（`severity`）——**本版做了根本性修正**

**v0.6 的做法**：按掩膜面积占比自动生成程度草案（如占比 0.000752 → "散在"）。
**问题**：这是**自造的临床标签**，不是任何分级体系里的语义，且与原文描述可能矛盾。

**v2.0 的分工**：

| 字段 | 性质 | 用途 |
|---|---|---|
| `lesion_area_ratio` | **定量证据**（浮点数，0—1） | 作为重排特征、趋势分析；**不作为临床程度标签** |
| `severity` | **临床描述**（枚举） | 只能来自：原文明确描述（`OFFICIAL`）/ 医学复核（`REVIEWED`） |
| `severity_source` | 来源标记 | 若为 `DERIVED_AREA`，该记录**不得作为程度金标准**，只能用于训练特征 |

**取值映射（仅当原文出现对应词时才填）**：

| 原文表述 | 填 |
|---|---|
| 无 | `NONE` |
| 少量 / 少许 | `FEW` |
| 散在 | `SCATTERED` |
| 中度 | `MODERATE` |
| 较重 / 较多 | `MARKED` |
| 严重 / 大量 | `SEVERE` |
| 原文未写 | `UNKNOWN` |

**禁止**：标注人员自行升级或降级程度；由面积占比反推程度。

### 4.4 证据强度（`evidence_strength`）——新增字段

| 枚举 | 含义 | 能否进 Gold |
|---|---|---|
| `DIRECT` | 原文直接描述该病灶 | ✅ |
| `INFERRED` | 由掩膜/规则推导 | ⚠️ 仅训练 |
| `NONE` | 无证据 | ❌ 不得入库 |

**铁律**：无原文支持 → 不生成正式标注；只有疾病名没有病灶 → **不补造病灶**。

## 5. 转诊判据（`referral_action`）——新增，全部可溯源

**依据**：《中国糖尿病防治指南（2024版）》（中华医学会糖尿病学分会，中华糖尿病杂志 2025;17(1):16-139）与《糖尿病视网膜病变防治专家共识》。

| 初筛结果 | `referral_action` | 时限 | 依据 |
|---|---|---|---|
| 无 DR、轻度 NPDR、无 DME | `ROUTINE_1Y` | 1 年内至眼科 | 指南·转诊章 |
| 中度 NPDR、非累及黄斑中心凹的 DME | `TIMELY_3_6M` | 3—6 个月内 | 指南·转诊章 |
| 重度 NPDR、PDR、累及黄斑中心凹的 DME | `IMMEDIATE` | 立即 | 指南·转诊章 |
| 突然视力丧失 / 视网膜剥离 / 视网膜前或玻璃体出血 / 虹膜红变 | `EMERGENCY_SAME_DAY` | **当天急诊** | 指南·转诊章 |
| 不符合以上任一条（如已确诊并稳定期） | `NONE` | — | 需记录判断依据 |

**纪律**：
- 每条转诊建议**必须**填 `referral_rule_id` 与 `guideline_ref`（质量规则 `AU-01`）。
- 系统不得输出"指南未覆盖"以外的自创时限；无法匹配规则时输出 `ABSTAIN`。
- 参考对照：《糖尿病视网膜病变社区筛查专家共识》给出分级诊疗与随访周期表，可作二级校验。

> ⚠️ **待医学顾问确认**：以上映射由公开指南整理，进入系统前须由医学顾问逐条签字确认（这是把顾问工作量压到"审核"而非"共建"的关键）。

## 6. 图文配对性质判定（`silver_pair_real` / `silver_pair_synthetic`）

### 6.1 判定通则

| 情形 | 归入 | `pair_source` / `generation_rule` |
|---|---|---|
| 同一病例的真实图像 + 真实临床报告 | **real** | `SAME_EXAM` |
| 图像 + 与该图像临床特征相关的文献证据片段 | **real** | `LITERATURE_LINKED`（**需记录关联依据**） |
| 图像 + 由该图像掩膜反向生成的描述 | **synthetic** | 规则名 + 版本 |
| 图像 + 模板/LLM 生成文本 | **synthetic** | 同上 |
| 来自公开图文数据集（MM-Retinal V2 等）的图像-报告对 | **real** | `SAME_EXAM` |

### 6.2 三条禁则

1. **合成配对的文本必须在 `text_span` 前加 `[合成]` 前缀**——防止在任何下游环节被误当成真实报告。
2. **合成配对严禁写入 `metric_validity=VALID` 的评测查询**（质量规则 `MT-01`）。
3. **不得把合成文本的重排结果作为"医学一致性提升"的证据**——那是循环论证。

> **为什么要把"由掩膜生成文本、再用文本查图像"视为无效**：这等价于用标签生成特征、再用特征预测标签。任何模型（哪怕随机初始化）都能拿到漂亮数字，这类指标在评审中一旦被识破，杀伤力远大于"指标低"。

## 7. 复核状态机

```
DRAFT ──► PENDING ──► APPROVED ──► (入库/Gold)
             │            │
             ├──► ARBITRATION ──► (裁决) ──► APPROVED / REJECTED
             └──► REJECTED ──► (归档，保留 deleted_at)
```

**规则**：
- 自动生成的一律 `DRAFT`；提交复核转 `PENDING`。
- **只有 `APPROVED` 的记录可进 Gold 层**（v0.6 手册已有此条，v2.0 由脚本强制）。
- 眼别、位置、程度**必须各自独立记录复核状态**，不得用整体状态替代。
- 测试集冻结后（`frozen_at` 非空），**不得**根据测试结果反向修改标注。

## 8. 标注质量验收标准

| 指标 | 阈值 | 检查方式 |
|---|---|---|
| 枚举越界率 | **0%** | 脚本全量扫描 |
| 必填空值率 | **0%** | 脚本全量扫描 |
| 证据原文可回溯率 | **100%**（`DIRECT` 类） | 抽样回原文比对 |
| 引用完整性（FK） | **100%** | 脚本校验 |
| 标注员间一致性（抽样 20 例双标） | Cohen's κ ≥ 0.7 | 双人独立标注 |
| 图像不可判读处理 | 标 `UNGRADABLE` 且不入核心测试集 | 流程检查 |

## 9. 待确认事项

1. **眼别推导方向**：需先在带真值的公开集上跑验证（§2.3）。在完成前，81 例眼别一律视为不可用，请确认是否同意暂时全部置为 `UNKNOWN`。
2. **1DD 标尺口径**：是否统一按"视盘直径"计算？不同标注员需统一，否则 DME 分级会漂移。
3. **`severity` 是否保留**：若医学顾问认为现有的"无/少量/散在/中度/较重/严重"六级无权威出处，可**整列废弃**，只保留 `lesion_area_ratio` 定量特征 + ICDR 图像级分级。这是最干净的选择，但会减少一条重排特征。
4. **转诊判据表**（§5）需医学顾问逐条签字确认。
